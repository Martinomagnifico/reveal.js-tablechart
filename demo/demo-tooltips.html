Tablechart

for Reveal.js: Tooltips

Tooltips

If a chart leaves numbers out, point at a row or tap it. A tooltip shows the name of the row and its values. This chart has three lines, so it shows no numbers.

Always or never

This chart shows all its numbers, so it has no tooltip by default. Add data-chart-tooltip="true" to give it one anyway, or data-chart-tooltip="false" to turn it off.

<figure class="tablechart" data-chart="column" data-chart-tooltip="true">
  <figcaption>
    <b>Apples picked</b><br><span>thousands</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>Spring</th><td>58</td></tr>
      <tr><th>Summer</th><td>72</td></tr>
      <tr><th>Autumn</th><td>70</td></tr>
      <tr><th>Winter</th><td>91</td></tr>
    </tbody>
  </table>
</figure>

With steps

A row that has not arrived yet has no tooltip. Go to the next step, then point at the new column.

<figure class="tablechart" data-chart="column" data-fragment data-chart-tooltip="true">
  <figcaption>
    <b>Apples picked</b><br><span>thousands</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>Spring</th><td>58</td></tr>
      <tr><th>Summer</th><td>72</td></tr>
      <tr><th>Autumn</th><td>70</td></tr>
      <tr><th>Winter</th><td>91</td></tr>
    </tbody>
  </table>
</figure>

Style it

The tooltip has its own variables for the background, text, border, corners, padding and shadow.

.darktip {
    --tablechart-tooltip-surface: #16323f;
    --tablechart-tooltip-color: #f3efe9;
    --tablechart-tooltip-border: 1px solid #4f9fd0;
    --tablechart-tooltip-radius: 0.6em;
}

That’s it!

For more about tooltips, see the Tablechart documentation.
