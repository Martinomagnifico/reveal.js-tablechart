Tablechart

for Reveal.js: Branding

Default

If no variables are set, a chart uses the text colour of the slide. Slices and lines get lighter one by one.

Where to set it

Set the variables on .reveal for the whole deck. To change one slide or one chart, set them on a class. In this demo, every slide uses its own class.

.reveal {
    --tablechart-bar-color: #e4572e;
}
.reveal .highlight {
    --tablechart-bar-color: #f2b134;
}

Your colour

One variable sets the colour of all bars.

.onecolour {
    --tablechart-bar-color: #e4572e;
}

Waterfall colours

Set the colours for rising steps, falling steps and totals. The value colour variables set the colour of the number inside each bar.

.warm {
    --tablechart-up-color: #b4552d;
    --tablechart-down-color: #d69a52;
    --tablechart-total-color: #cfc4b4;
    --tablechart-up-value-color: #ffffff;
    --tablechart-down-value-color: #3a2312;
    --tablechart-total-value-color: #3a2312;
}

A palette

Set --tablechart-color-1, -2 and on. Slices use them in order. If a colour is not set, that slice uses the default.

.fruity {
    --tablechart-color-1: #b4552d;
    --tablechart-color-2: #d69a52;
    --tablechart-color-3: #7fa87f;
    --tablechart-color-4: #cfc4b4;
}

The same palette for lines

If a line chart has several lines, the lines use the palette too.

.fruity {
    --tablechart-color-1: #b4552d;
    --tablechart-color-2: #d69a52;
    --tablechart-color-3: #7fa87f;
}

Legend

A legend is as wide as its items. These variables set its background, border, padding and corners.

.boxed {
    --tablechart-legend-surface: rgba(255, 255, 255, 0.06);
    --tablechart-legend-border: 1px solid rgba(255, 255, 255, 0.3);
    --tablechart-legend-padding: 0.3em 0.8em;
    --tablechart-legend-radius: 0.4em;
}

Background

Lighter slices and lines are a mix of their colour and the background colour: that of the slide, or else that of the deck. If a chart has --tablechart-surface, that colour is its background.

<figure data-chart="donut" style="--tablechart-surface: white">

Text

Charts use the font of the deck. These variables set the sizes.

.sizes {
    --tablechart-font-size: 0.5em;
    --tablechart-value-size: 1.6em;
    --tablechart-name-size: 0.75em;
}

Baseline and connectors

.dotty {
    --tablechart-connector-width: 2.5px;
    --tablechart-connector-dash: 0 6;
    --tablechart-connector-opacity: 1;
    --tablechart-baseline-width: 2px;
    --tablechart-baseline-opacity: 1;
}
/* A dash of 0 with round ends is a dot. */
.dotty .tablechart-connector {
    stroke-linecap: round;
}

The badge

.pill {
    --tablechart-badge-radius: 0.4em;
    --tablechart-badge-padding: 0.4em 0.8em;
}

Animation speed

.slow {
    --tablechart-animation-element-duration: 0.9s;
}

That’s it!

For all variables, see the Tablechart documentation.
