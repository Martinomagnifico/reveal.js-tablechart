Tablechart

for Reveal.js: Line charts

Line chart

Each row is a point. The line builds from left to right.

<figure class="tablechart" data-chart="line">
  <figcaption>
    <b>Rainfall at the orchard</b><br><span>millimetres</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>Jan</th><td>88</td></tr>
      <tr><th>Feb</th><td>74</td></tr>
      <tr><th>Mar</th><td>61</td></tr>
      <tr><th>Apr</th><td>49</td></tr>
    </tbody>
  </table>
</figure>

Annotations

Annotations work the same as in the other chart types.

Step by step

Add data-fragment to the figure to show one point per step.

<figure class="tablechart" data-chart="line" data-fragment>
  <figcaption>
    <b>Apples per tree</b><br><span>each</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>2022</th><td>91</td></tr>
      <tr><th>2023</th><td>102</td></tr>
      <tr><th>2024</th><td>116</td></tr>
    </tbody>
  </table>
</figure>

Several lines

Each value column is a line. The column header is shown as the name at the end of the line.

<figure class="tablechart" data-chart="line" data-chart-prefix="lineseries">
  <figcaption>
    <b>Apples per tree</b><br><span>each</span>
  </figcaption>
  <table>
    <thead>
      <tr><th>Year</th><th>North</th><th>South</th></tr>
    </thead>
    <tbody>
      <tr><th>2016</th><td>41</td><td>30</td></tr>
      <tr><th>2019</th><td>58</td><td>39</td></tr>
      <tr><th>2022</th><td>77</td><td>52</td></tr>
      <tr><th>2025</th><td>105</td><td>61</td></tr>
    </tbody>
  </table>
</figure>

Legend

Add data-chart-legend to the figure to show the names in a legend under the chart, instead of at the end of the lines.

<figure class="tablechart" data-chart="line" data-chart-prefix="linelegend" data-chart-legend>
  <figcaption>
    <b>Apples per tree</b><br><span>each</span>
  </figcaption>
  <table>
    <thead>
      <tr><th>Year</th><th>North</th><th>South</th></tr>
    </thead>
    <tbody>
      <tr><th>2016</th><td>41</td><td>30</td></tr>
      …
      <tr><th>2025</th><td>105</td><td>61</td></tr>
    </tbody>
  </table>
</figure>
