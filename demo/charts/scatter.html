Tablechart

for Reveal.js: Scatter charts

Scatter chart

Each row is a marker. The first value column is the position across, the second the position up. Their headers are the titles of the axes.

<figure class="tablechart" data-chart="scatter">
  <figcaption><b>Harvest and price per variety</b></figcaption>
  <table>
    <thead>
      <tr>
        <th></th>
        <th>Harvest per tree (kg)</th>
        <th>Price per kg (€)</th>
      </tr>
    </thead>
    <tbody>
      <tr><th>Elstar</th><td>62</td><td>1.20</td></tr>
      <tr><th>Jonagold</th><td>75</td><td>1.05</td></tr>
      …
    </tbody>
  </table>
</figure>

Bubbles

A third value column sets the size of each marker: its area matches the value.

<figure class="tablechart" data-chart="scatter">
  <figcaption>
    <b>Harvest, price and number of trees</b>
  </figcaption>
  <table>
    <thead>
      <tr>
        <th></th>
        <th>Harvest per tree (kg)</th>
        <th>Price per kg (€)</th>
        <th>Trees</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th>Elstar</th>
        <td>62</td>
        <td>1.20</td>
        <td>420</td>
      </tr>
      …
    </tbody>
  </table>
</figure>

Groups

Add data-group to the header of a column with names. Each group has its own colour, shape and entry in the legend.

.scattergroups {
    --tablechart-color-1: #4f9fd0;
    --tablechart-color-2: #e0a35b;
}

Axes and gridlines

data-chart-scale-x and data-chart-scale set the axes: two numbers for where they start and end, or more for the numbers along them. data-chart-grid adds gridlines.

<figure class="tablechart" data-chart="scatter" data-chart-grid data-chart-scale-x="0 100" data-chart-scale="0 0.5 1 1.5 2">
  <figcaption><b>From zero</b></figcaption>
  <table>
    <thead>
      <tr>
        <th></th>
        <th>Harvest per tree (kg)</th>
        <th>Price per kg (€)</th>
      </tr>
    </thead>
    <tbody>
      <tr><th>Elstar</th><td>62</td><td>1.20</td></tr>
      <tr><th>Jonagold</th><td>75</td><td>1.05</td></tr>
      …
    </tbody>
  </table>
</figure>
