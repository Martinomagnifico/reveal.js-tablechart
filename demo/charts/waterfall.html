for Reveal.js: Waterfalls

Steps and totals

Rows with data-kind="total" start at the baseline. The other rows are steps up or down from the running total.

<tr data-kind="total"><th>Picked</th><td>74.5</td></tr>
<tr><th>Windfalls</th><td>28.2</td></tr>
<tr data-kind="total"><th>Pressed</th><td>102.7</td></tr>

Totals are not calculated

Tablechart shows the total you write. It does not add up the steps, so a rounded total stays as you wrote it.

Numbers

If a bar is tall enough, its number is shown inside it. If not, the number is shown next to it.
