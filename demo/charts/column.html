Tablechart

for Reveal.js: Column charts

Column chart

<figure class="tablechart" data-chart="column">
  <figcaption>
    <b>Apples picked</b><br><span>thousands</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>Spring</th><td>58</td></tr>
      <tr><th>Summer</th><td>72</td></tr>
      <tr><th>Autumn</th><td>70</td></tr>
      <tr><th>Winter</th><td>91</td></tr>
    </tbody>
  </table>
</figure>

Axis and gridlines

Add data-chart-axis for the numbers along the value axis, and data-chart-grid for a line at each of them. The scale then ends on a number of the axis.

<figure class="tablechart" data-chart="column" data-chart-axis data-chart-grid>
  <figcaption>
    <b>Apples picked</b><br><span>thousands</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>Spring</th><td>58</td></tr>
      <tr><th>Summer</th><td>72</td></tr>
      <tr><th>Autumn</th><td>70</td></tr>
      <tr><th>Winter</th><td>91</td></tr>
    </tbody>
  </table>
</figure>

More rows

Add more rows to the table. The columns get narrower to fit.

Decimals

Numbers are shown with the decimals you write, so 1.0 stays 1.0. The decimal separator follows the language of the document.

<tr><th>Apples</th><td>8.2</td></tr>
<tr><th>Oranges</th><td>10.0</td></tr>
<tr><th>Lemons</th><td>6.5</td></tr>

Grouped columns

If the table has more than one value column, each row is a group. The column headers are the names in the legend.

<figure class="tablechart" data-chart="column">
  <figcaption>
    <b>Apples sold by variety</b><br><span>thousands</span>
  </figcaption>
  <table>
    <thead><tr><th></th><th>2022</th><th>2026</th></tr></thead>
    <tbody>
      <tr><th>Elstar</th><td>118</td><td>131</td></tr>
      <tr><th>Jonagold</th><td>140</td><td>135</td></tr>
      <tr><th>Braeburn</th><td>109</td><td>121</td></tr>
    </tbody>
  </table>
</figure>

Stacked columns

Add data-chart-stack to the figure. The values of a row are on top of each other, with the total above.

Step by step

Add data-fragment to a row to show it on a step. Rows with the same data-fragment-index appear together.

<tr data-fragment data-fragment-index="1">
  <th>Apples, north</th>
  <td>58</td>
</tr>
<tr data-fragment data-fragment-index="1">
  <th>Oranges, north</th>
  <td>72</td>
</tr>
<tr data-fragment data-fragment-index="2">
  <th>Apples, south</th>
  <td>70</td>
</tr>
<tr data-fragment data-fragment-index="2">
  <th>Oranges, south</th>
  <td>91</td>
</tr>

Break the scale

If one value is much larger than the others, add an axis-break annotation. Above the break, bar heights are not to scale, so every bar shows its number.

<div class="chart-annotations">
  <span data-annotation="axis-break" data-at="20"></span>
</div>

Several charts on a slide

A chart fills the width of its container. To place several charts, use your own grid.
