Tablechart

for Reveal.js: Area charts

Area chart

A line chart with the space under the line filled. The fill fades in while the line builds.

<figure class="tablechart" data-chart="area">
  <figcaption>
    <b>Visitors to the orchard</b><br><span>thousands</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>2021</th><td>12</td></tr>
      <tr><th>2022</th><td>19</td></tr>
      <tr><th>2023</th><td>24</td></tr>
      <tr><th>2024</th><td>31</td></tr>
      <tr><th>2025</th><td>38</td></tr>
    </tbody>
  </table>
</figure>

Several areas

Each value column is an area. The areas overlap, so each one is see-through.

Stacked areas

Add data-chart-stack to the figure. Each area starts on top of the one before it.

Steps

Add data-chart-shape="step" to the figure. Each value is flat across its row, and a number is shown only where the value changes.

Step by step

Add data-fragment to the figure to show one point per step.

<figure class="tablechart" data-chart="area" data-fragment>
  <figcaption>
    <b>Visitors to the orchard</b><br><span>thousands</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>2021</th><td>12</td></tr>
      <tr><th>2022</th><td>19</td></tr>
      <tr><th>2023</th><td>24</td></tr>
      <tr><th>2024</th><td>31</td></tr>
      <tr><th>2025</th><td>38</td></tr>
    </tbody>
  </table>
</figure>
