Tablechart

for Reveal.js: Bar charts

Names beside the bars

In a bar chart, the names are shown to the left of the bars. Use it when the names are long.

<figure class="tablechart" data-chart="bar">
  <figcaption>
    <b>Picked by variety</b><br><span>thousands</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>Bramley seedling</th><td>31.4</td></tr>
      <tr><th>Cox's orange pippin</th><td>27.8</td></tr>
      …
    </tbody>
  </table>
</figure>

Numbers

If a bar is long enough, its number is shown inside it. If not, the number is shown after the bar.

Grouped bars

If the table has more than one value column, each row is a group of bars. The column headers are the names in the legend.

<figure class="tablechart" data-chart="bar">
  <figcaption>
    <b>Apples sold by variety</b><br><span>thousands</span>
  </figcaption>
  <table>
    <thead><tr><th></th><th>2022</th><th>2026</th></tr></thead>
    <tbody>
      <tr><th>Elstar</th><td>118</td><td>131</td></tr>
      <tr><th>Jonagold</th><td>140</td><td>135</td></tr>
      <tr><th>Braeburn</th><td>109</td><td>121</td></tr>
    </tbody>
  </table>
</figure>

Step by step

Add data-fragment to the figure to show one bar per step.

<figure class="tablechart" data-chart="bar" data-fragment>
  <figcaption>
    <b>Picked by variety</b><br><span>thousands</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>Bramley seedling</th><td>31.4</td></tr>
      <tr><th>Cox's orange pippin</th><td>27.8</td></tr>
      <tr><th>Egremont russet</th><td>18.2</td></tr>
    </tbody>
  </table>
</figure>
