Tablechart

for Reveal.js

Sometimes you just want a simple graph in a Reveal.js presentation. Simple colors and style, simple markup. Tablechart does that.

Six types:

Set it up

It’s easy

JavaScript

Download the plugin folder and make a reference to it in the Reveal plugin options:
(The CSS file is autoloaded, but you can also load it manually if you want to change it.)

<script src="plugin/tablechart/tablechart.js"></script>
<script>
    Reveal.initialize({
        plugins: [ Tablechart ]
    });
</script>

Or install it with npm (npm i reveal.js-tablechart) and import it:

import Tablechart from 'reveal.js-tablechart';
import 'reveal.js-tablechart/tablechart.css';
Reveal.initialize({
    plugins: [ Tablechart ]
});

HTML Markup

To create a chart, add a table inside the Tablechart figure markup. The first cell of a row is the label, the second the value.

<figure class="tablechart" data-chart="column">
  <table>
    <tbody>
      <tr><th>Spring</th><td>58</td></tr>
      <tr><th>Summer</th><td>72</td></tr>
      <tr><th>Autumn</th><td>70</td></tr>
    </tbody>
  </table>
</figure>

HTML Markup

Or from a JSON source:

<div class="tablechart" data-chart="column" data-chart-src="assets/data/apples.json"></div>

Add a title and subtitle

<figure class="tablechart" data-chart="column">
  <figcaption>
    <b>Apples per tree</b><br><span>each</span>
  </figcaption>
  <table>
    <tbody>
      <tr><th>2022</th><td>91</td></tr>
      <tr><th>2023</th><td>102</td></tr>
      <tr><th>2024</th><td>116</td></tr>
    </tbody>
  </table>
</figure>

Add annotations

<figure class="tablechart" data-chart="column">
  <table>
    <tbody>
      <tr><th>2022</th><td>91</td></tr>
      <tr><th>2023</th><td>102</td></tr>
      <tr><th>2024</th><td>116</td></tr>
    </tbody>
  </table>
  <div class="chart-annotations">
    <span data-annotation="trend" data-years="2" data-at="0.5">
      <span class="tablechart-caption">Per year</span>
      <span>+13%</span>
    </span>
  </div>
</figure>
