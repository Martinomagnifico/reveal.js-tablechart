Tablechart

for Reveal.js: Adding annotations

Bracket

A bracket shows the change between two bars. If the chart has only two bars, no attributes are needed.

<div class="chart-annotations">
  <span data-annotation="bracket">+11%</span>
</div>

Choose the bars

If the chart has more bars, set data-from and data-to to the row numbers. The first row is 1.

<span data-annotation="bracket" data-from="2" data-to="5">
  +45%
</span>

Trend

A trend arrow runs from the first value to the last.

<span data-annotation="trend" data-years="4" data-at="0.46">
  <span class="tablechart-caption">A year</span>
  <span>+12%</span>
</span>

Check the rate

Set data-years to the number of years. Tablechart calculates the rate, and shows a warning in the console if it is different from yours. Your number is always the one shown.
